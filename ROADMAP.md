# Roadmap

## Completed in v1.4.1

- Event-driven live stream
- Project-scoped, scoped multi-client tokens
- Raw-data separation
- Audit logging and metrics
- Rate limiting and configurable concurrency
- HTTP request-smuggling defenses
- Reproducible/verified build pipeline
- Selected-interface and explicit all-interface network binding

## Future optional work

- OAuth/OIDC through an external local reverse proxy
- HAR and SQLite streaming exports
- Persistent disk-backed event queue for multi-day client outages
- Native client SDK generation from OpenAPI
- Signed release artifacts and SBOM publication
